## Selected Projects

### Lightweight Semantic Water-Level Inference on STM32 for Edge Flood Monitoring

First-author research accepted for Oral Presentation at **IEEE GCCE 2026**. The study investigates event-aware water-level semantic inference under scarce flood-event data, teacher-guided lightweight modeling, and C99 deployment of a depth-3 Decision Tree on an STM32L476RG.

**Tech:** Python · C · CatBoost · Decision Tree · STM32L476RG · Edge AI  
**Repository:** [stm32-edge-flood-monitoring](https://github.com/tzu-hsiang-weng/stm32-edge-flood-monitoring)

### VoI-Driven Transport Selection for Heterogeneous LoRa/Wi-Fi IoT

Undergraduate capstone project integrating water-level semantic inference with adaptive LoRa/Wi-Fi transmission and MQTT-based system integration. My primary contribution focused on water-level semantic inference, lightweight model development, and Edge AI integration.

**Tech:** Python · IoT · LoRa · Wi-Fi · MQTT · Edge AI  
**Repository:** [VoI-Driven-Transport-Selection-for-Heterogeneous-LoRa-Wi-Fi-IoT-with-Unified-MQTT-Abstraction](https://github.com/tzu-hsiang-weng/VoI-Driven-Transport-Selection-for-Heterogeneous-LoRa-Wi-Fi-IoT-with-Unified-MQTT-Abstraction)
